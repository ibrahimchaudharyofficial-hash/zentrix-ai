# ZENTRIX AI v1.7.0

## New
- Math Arcade with Quick Quiz, Equation Rush, Number Quest, Math Match, Logic Lab and True or False modes.
- Subject selection including Algebra, Calculus, Arithmetic, Geometry, Trigonometry, Statistics, Probability, Matrices and Physics.
- Easy, Medium, Intermediate, Hard, Expert, Pro and Adaptive difficulty.
- 5, 10, 15 and 20 question rounds with answer explanations.
- Local SQLite progress tracking for Arcade attempts and accuracy.
- Offline topic tutor with optional Gemini-generated explanations when configured.
- Animated interface effects enabled by default.
- Opt-in About ZENTRIX description in Settings.

## Compatibility and privacy
- Existing solver, Graph Studio, Matrix Lab, Learning Studio, formula reference, photo OCR, Proof Auditor, Error Coach and optional Gemini settings are retained.
- Arcade progress remains in `zentrix_progress.sqlite3` on the same computer.
- No paid API or account is required for Arcade.
- Existing mathematical solver remains local-first.
