# Zentrix AI 1.2.0

## More capable word-problem solver
- Added triangle-area word problems with generated labelled triangle figures.
- Added circle-area and circumference word problems, accepting explicitly stated radius or diameter.
- Added mathematical SVG renderers for triangle and circle diagrams.
- Preserved existing ladder and rectangle problem support.
- Added regression tests for the new problem types.

## Scope
The guided solver recognises supported patterns; it does not claim to solve every possible natural-language problem.
