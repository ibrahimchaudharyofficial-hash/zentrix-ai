# ZENTRIX AI 3.0.0

**Mathematics Without Limits — Mathematical Research Platform**

## Major additions
- Research Lab for symbolic calculus, limits, roots, Taylor expansions, definite integrals and numerical sampling.
- Exact identity verification with numerical spot checks and proof-scope warnings.
- Three-pass browser-side OCR using enhanced grayscale, contrast and Otsu-threshold image variants.
- Printable research reports (browser print / Save as PDF).
- Learning progress estimates based on saved Math Arcade attempts, with evidence confidence.
- Structured knowledge topic map.
- Versioned API and updated release documentation.

## Preserved
- Existing solver, step-by-step explanations, verification, graph studio, matrix lab, learning studio, formula reference, proof auditor, error coach, history, settings and Math Arcade.
- Local-first calculations and optional Gemini assistance.
- Laptop-first layout and existing animation system.

## Known limitations
- OCR remains printed-text oriented and requires a browser download of Tesseract.js/language data on first use. Review all recognised equations manually.
- Identity verification is not a general theorem prover.
- Graph Studio is 2D; no full 3D graphing engine is included.
- Learning estimates use arcade attempts only; no complete curriculum mastery or spaced-repetition scheduler is claimed.
- The research endpoint supports one independent variable and bounded expression sizes.
