# Zentrix AI 1.1.0

## Word Problem & Diagram Solver (initial release)
- Added deterministic support for ladder-against-wall right-triangle problems.
- Added rectangle area and perimeter statement problems.
- Automatically generates labelled SVG figures from computed mathematical values.
- Shows formulas, substitutions, calculations, and independent checks.
- Figures are mathematically generated, not AI illustrations.
- Existing solver, Gemini settings, and other features are retained.

## Scope
This is the first focused release of the feature. It currently supports these recognised ladder/right-triangle and rectangle statement patterns; it is not yet a universal word-problem solver. More problem families and figure types can be added in later releases.
