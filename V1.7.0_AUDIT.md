# ZENTRIX AI v1.7.0 — Source audit and release scope

## Baseline inspected

The supplied v1.6.0 archive contains 41 files and approximately 1.60 MB of uncompressed content. Its main application is a FastAPI backend (`backend/main.py`), a SymPy-based mathematical engine (`backend/engine.py`), and a single-page HTML/CSS/JavaScript frontend (`backend/static/index.html`). The project uses no React, Vue, or other large frontend framework. The v1.6.0 release report records 43 passing automated tests; independently running `python -m pytest -q tests` reproduced 43 passes.

A root-level `python -m pytest -q` initially failed during collection because `run_100_test.py` executed on import and wrote to a stale absolute path under `/mnt/data/zentrix_v15_work`. v1.7.0 adds `pytest.ini` to restrict normal test discovery to `tests/` and fixes the benchmark output path to be relative to the project directory.

## Preserved v1.6.0 capabilities

- Local symbolic mathematics through SymPy and the existing safe parser.
- Existing solver domains, worked steps, selected numerical checks, proof auditor and misconception coach.
- Graph Studio, Matrix Lab, Learning Studio, formula reference, history and photo OCR flow.
- Optional Gemini key settings; no API key is required for local solving.
- Existing light/dark themes and Windows/macOS/Linux launch scripts.

## v1.7.0 additions

- Math Arcade with selectable subjects: Algebra, Calculus, Arithmetic, Geometry, Trigonometry, Statistics, Probability, Matrices and Physics.
- Six selectable game modes: Quick Quiz, Equation Rush (timed round), Number Quest, Math Match, Logic Lab and True or False.
- Easy, Medium, Intermediate, Hard, Expert, Pro and Adaptive difficulty; Algebra and Calculus are preselected and Intermediate is the default.
- 5, 10, 15 and 20 question rounds, answer feedback and short explanations.
- Local SQLite Arcade attempt history and aggregate accuracy, with no login or cloud sync.
- Offline Tutor explanations for supported topics; optional Gemini-generated guidance when a key is configured. Tutor responses are explicitly not treated as verified calculations.
- Opt-in About ZENTRIX description in Settings.
- Mandatory, lightweight CSS animations for page/card entrance, hover states and the Arcade banner. Animations use opacity/transform for the shimmer and interactions; no new animation library or game engine was added.
- Removed remote Google Fonts downloads; system font fallbacks are used. OCR remains lazy-loaded when requested.

## Low-device review

- Frontend remains a single HTML file with native JavaScript; no new framework or game engine.
- Added frontend JavaScript is approximately 38 KB; complete HTML is approximately 85 KB before compression.
- Arcade question generation runs in the browser and does not require repeated solver API calls. SQLite writes are short and indexed by subject/date.
- The active Equation Rush timer exists only while a round is running and is cleared between questions.
- Existing graph and OCR workflows remain on-demand; OCR's Tesseract script is injected only when the user starts photo recognition.
- No physical benchmark was possible on the target i5-1145G7/8 GB laptop in this environment. The design avoids new heavyweight dependencies, but actual device FPS/startup memory should be measured on that machine before making numerical performance claims.

## Known limitations

- Adaptive Arcade difficulty uses the selected subjects' aggregate correct-answer ratio. It is a lightweight first adaptive step, not a full mastery model, spaced-repetition scheduler or misconception-aware curriculum.
- The current game-question bank is template-based and intentionally small in mathematical scope. Pro difficulty raises selected parameter ranges; it is not a complete graduate-level question bank.
- Math Match currently presents expression-to-answer matching as a multiple-choice round; it is not a full card-flipping memory game.
- Local progress is a single local installation's SQLite record, with no named multi-user profiles, cloud sync or cross-device transfer.
- Offline Tutor content is a concise built-in reference for the supported topics. Optional Gemini output may be incorrect and is not mathematically verified; use the local solver and verifier for exact results.
- KaTeX remains an external CDN dependency for rich formula rendering. Core backend calculations are local, but offline rich typesetting may fall back to plain text if the browser has not cached KaTeX.
- A real browser automation pass was attempted, but this execution environment blocked loopback browser navigation (`ERR_BLOCKED_BY_ADMINISTRATOR`). Static JavaScript syntax, backend APIs and automated tests were validated instead.
